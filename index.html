Course Allocation Guidelines

Note on Course Allocation
for Faculty Members (FMs)

Each FM may select a maximum of 2 courses in total, in any of the following combinations:

  • 2 MS courses
  • 2 PhD courses
  • 1 MS + 1 PhD course

The program has 5 clusters — Electromagnetics & Photonics, Communication & Signal Processing, Power Systems, Control Systems, and Machine Learning & Image Processing — each capped independently. Within each cluster, an FM may offer:

  • 1 course for MSEE Semester 1
  • 2 courses for MSEE Semester 3
  • 3 courses for PhD EE Semester 1
Rationale

For MSEE Semester 1, students require only 1 elective. Offering 1 course per cluster (5 total) provides sufficient choice while maintaining viable class sizes.

For MSEE Semester 3, students require 2 electives, but enrollment is usually limited (7–9 students). The total number of offered courses must remain controlled to avoid classes with very low enrollment.

This policy ensures a balance between student choice and sustainable class strength.
